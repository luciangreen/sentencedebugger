# sentencedebugger

Complex Multi-Stage Sentence Debugger in SWI-Prolog.

## Usage

Load `main.pl` in SWI-Prolog and call one of:

- `debug_sentence/4`
- `debug_sentence_to_file/4`
- `debug_predicate_to_file/4`
- `debug/4`

## Tests

Run:

```bash
swipl -q -f none -s /home/runner/work/sentencedebugger/sentencedebugger/tests/run_tests.pl
```
